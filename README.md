## How to Run

### What you need
- Node.js (https://nodejs.org)
- The Expo Go app on your phone (or a way to open the app in a browser)

### 1. Install everything
From the main folder (Team_Best_Monorepo), run:

```
npm run install:all
```

### 2. Start the server
```
npm run server
```
The server runs at http://localhost:3000. To check that it works, open that address in a browser. You should see: {"message":"Server running"}

### 3. Start the client
Open a second terminal, go to the main folder, and run:

```
npm run client
```
Then follow the instructions Expo shows (scan the QR code with Expo Go, or press the key shown for the web version).

### 4. Run the tests
Server tests:
```
cd server
npm test
```
Client tests:
```
cd client
npm test
```



## Vision Statement

The Church Match app is for College Students who struggle to find church communities away from home. The Church Match App is a suggestion generating and experience quantifying app that provides suggestions based on user parameters and feedback from previous church suggestions. Unlike utilizing google reviews for churches,or word of mouth from upperclassmen our app will provide greater catering to an individuals theological or experiential preferences and additionally will provide services for the user once they have committed to a church community for becoming more active.
