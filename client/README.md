1. The default template

adds file based routing via Expo Router and pre-built components, icon support, light/dark styling and a structured layout with app/ directory.

2. The styling and app widges

are specified using React Native's StyleSheet.create() method, which applies JavaScript object properties (like Flexbox layout) directly to component style props.

3. app/ directory

Expo Router stores the application's file-based navigation routes, screens, and layout files within the app/ directory.

4. components/ directory

Expo stores reusable React UI components (like buttons, icon vectors, or image view wrappers) that are imported into various screen routes.
